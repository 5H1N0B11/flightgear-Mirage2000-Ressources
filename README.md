# Purpose of this Repo

This repository contains the ressources for the [FlightGear Mirage 2000](https://github.com/5H1N0B11/flightgear-mirage2000). These ressources are e.g. original 3D files (Blender .blend), originals images (GIMP .xcf), etc.

Cf. the readme files in the subfolders for specific contents and instructions.

| Directory                             | Content                                                                                      |
| ------------------------------------- | -------------------------------------------------------------------------------------------- |
| Service-door                          | Pin-up art ect. for service doors in nose area                                               |
| aircraft                              | Outside and inside incl. cockpit for <= 2024.1 versions based on ac3d                        |
| cockpit_d                             | 2000D version of cockpit in Blender with gltf target format for HDR / PBR version of FG NEXT |
| docs                                  | Development documents as well as source for aircraft manual                                  |
| effects                               | As the name says                                                                             |
| original_d_cockpit_blend_chunchunmaru | Original donated Blender files for 2000D cockpit                                             |
| tank                                  | External tanks                                                                               |
| weapons                               | Weapons specific for Mirage 2000 (not inherited from OPRF)                                   |

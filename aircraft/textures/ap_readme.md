## Button

### ALT, ALT AFF, Empty

width / height ratio: 6.8 / 3.5 = 1.943

Based on font height 18 -> 28 pixels for height (chosen) -> 54 pixels

### L / G

width / height ratio: 3.2 / 3.5 = 0.914

28 pixels for height -> 26 pixels (width)

### P / A

width / height ratio: 3.1 / 7.5

Based on 28 pixels = 3.5 -> 7.5/3.5 * 28 = 60 pixels height

3.1/7.5*60 = 25 pixels width

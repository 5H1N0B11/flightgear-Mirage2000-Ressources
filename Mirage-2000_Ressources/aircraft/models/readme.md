# Content

This directory has the original Blender 3d files as well as derived *.ac files and *.png files for all originally modelled Mirage 2000 variants.

Most ac-files are exports from the Blender file `m2000B-3.blend`. Export are made by:

* selecting all elements within a collection and group
* File - Export - AC3D: `-Z Forward`, `Y Up`, `Matrices apply before export`, `Only View Layers` = deselected, `Selection Only` = selected.
